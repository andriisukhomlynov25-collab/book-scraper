# Book Price Scraper

Автоматизований інструмент для збору цін на книги з різних інтернет-магазинів та запису результатів у Google Таблицю.

---

## Як це працює

### Загальна схема

```
Google Sheets (список книг)
        ↓
  Serper API (пошук)         ← знаходить до 3 сайтів для кожної книги
        ↓
 ThreadPoolExecutor           ← відкриває всі 3 сайти одночасно
  ┌─────┬─────┬─────┐
  │  🌐 │  🌐 │  🌐 │         ← кожен потік — окремий Chrome
  └──┬──┴──┬──┴──┬──┘
     ↓     ↓     ↓
  ціна  ціна  ціна            ← скріншот + завантаження на Drive
        ↓
 Google Sheets batch_update   ← F/G/H = ціни (посилання на скріншот), I = середня
```

### Детально

1. **Зчитування таблиці** — скрипт відкриває перший аркуш (`sheet1`). Рядки починаються з 2-го (1-й — заголовки). Назва книги береться зі стовпця C.

2. **Пошук через Serper** — по назві книги виконується Google-пошук з обмеженням `site:` по всіх підтримуваних магазинах. Обираються до 3 унікальних доменів. Якщо AbeBooks не потрапив у результати — він додається як запасний варіант через форму пошуку.

3. **Паралельний скрапінг** — кожне посилання відкривається в окремому потоці (`ThreadPoolExecutor`). Кожен потік створює власний екземпляр Chrome та власний клієнт Google Drive API (httplib2 не є потокобезпечним). `threading.Lock()` захищає ініціалізацію Chrome від race condition.

4. **Спеціальна обробка по сайтах:**
   - **Amazon** — спочатку встановлює ZIP-код `10001` (США) для отримання цін у доларах
   - **eBay** — «прогрівається» через головну сторінку перед переходом на товар
   - **AbeBooks (форма пошуку)** — вводить назву книги вручну й відправляє форму
   - **Всі сайти** — автоматично закриває cookie-банери та поп-апи

5. **Витягування ціни** — використовує CSS-селектори для кожного сайту + регулярні вирази для Allegro (`zł`), ThriftBooks (`$`), OLX. Перевіряє `is_displayed()`, щоб пропустити приховані елементи.

6. **Скріншот** — після знаходження ціни робить скріншот сторінки, завантажує на Google Drive (відкритий доступ). У таблицю записується формула `=HYPERLINK(посилання; "ціна")`.

7. **Запис у таблицю** — після завершення всіх потоків для одної книги, головний потік записує одним `batch_update`:
   - Стовпець F, G, H — ціни з посиланнями на скріншоти
   - Стовпець I — середня ціна

## Налаштування

### 1. Залежності

```bash
pip3 install undetected-chromedriver selenium gspread \
             google-api-python-client google-auth setuptools requests
```

### 2. Chromedriver (macOS)

`undetected-chromedriver` автоматично завантажує та патчить chromedriver під час першого запуску. Після цього macOS Gatekeeper може заблокувати бінарник:

1. Запустіть скрипт один раз — він падатиме з помилкою
2. Відкрийте **Системні налаштування → Конфіденційність і безпека**
3. Натисніть «Дозволити» для заблокованого chromedriver
4. Або: надайте VS Code дозвіл керувати іншими програмами

### 3. Google credentials

Покладіть файл `credentials.json` (сервісний акаунт) у папку `book-scraper/`.
Сервісний акаунт повинен мати доступ до:
- Google Sheets (редагування таблиці)
- Google Drive (завантаження файлів у папку)

### 4. Конфігурація скрипта

У `text1.py` змініть:

```python
SPREADSHEET_ID = '...'          # ID таблиці Google Sheets
SHARED_DRIVE_FOLDER_ID = '...'  # ID папки Google Drive для скріншотів
SERPER_API_KEYS = ['...']       # Ключі Serper API (ротація при вичерпанні квоти)
```

У `config.py` змініть при необхідності:

```python
CHROME_VERSION = 147            # Має відповідати встановленій версії Chrome
```

## Запуск

### Головний скрипт

```bash
cd book-scraper/.venv
python3 -u text1.py
```

> Прапор `-u` вимикає буферизацію stdout, тому лог видно в реальному часі.

### Тест окремого парсера

```bash
cd book-scraper/.venv
python3 test_amazon.py
python3 test_yakaboo.py
# тощо
```

Кожен тест-файл відкриває браузер, заходить на конкретну сторінку книги та виводить знайдену ціну.

## Вирішення проблем

**`no such window: target window already closed`**
Chromedriver бінарник був перепатчений. Переконайтесь, що у `uc.Chrome()` завжди передається `driver_executable_path=DRIVER_PATH` з `config.py` — це обходить перепатчування.

**`ціну не знайдено` для більшості книг**
Нормально для рідкісних/старих книг, яких немає на популярних майданчиках. Serper не знаходить прямих посилань, AbeBooks також нічого не повертає.

**macOS блокує chromedriver**
Дивіться розділ «Налаштування → Chromedriver» вище.

**Порожній вивід при запуску у фоні**
Використовуйте `python3 -u text1.py` (без буферизації).

**Serper API закінчився**
Додайте більше ключів у масив `SERPER_API_KEYS` у `text1.py`. Скрипт автоматично перемикається на наступний ключ при вичерпанні.
